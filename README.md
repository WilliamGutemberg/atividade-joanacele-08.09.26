Projeto em Linguagem C
Objetivo
Praticar programação e desenvolver o raciocínio lógico utilizando a linguagem C.

Atividades
Foram realizados exercícios sobre números pares e ímpares, operações matemáticas, sistema de caixa e classificação de triângulos.

Conclusão
O projeto ajudou a desenvolver conhecimentos básicos de programação, lógica e linguagem C.
